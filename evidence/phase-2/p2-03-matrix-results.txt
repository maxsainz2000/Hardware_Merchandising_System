=== 1. Coverage: every controller action declares its authorization intent ===
$ dotnet test ... --filter "FullyQualifiedName~AuthorizationMatrixTests"
  Passed EveryControllerAction_DeclaresAllowAnonymousOrARegisteredPolicy [484 ms]

Every ControllerActionDescriptor in the API assembly was classified as
exactly one of: AllowAnonymous (HealthController.GetHealth,
AuthController.Login, MaintenanceController.GetStatus), a named Policy
present in PolicyRegistry.Definitions (AdminController.Ping,
MaintenanceController.Enter/Release, InventoryController.DecrementStock),
or the explicit "authenticated, no policy" allowlist
(AuthController.GetCurrentUser, AuthController.Logout - spec section 13:
"/me" is any authenticated role). Zero actions fell outside all three -
had any existed, this test would have failed by name. A future endpoint
added without authorization, or naming a policy PolicyRegistry does not
register, fails this test rather than shipping untested (done-when box 4).

=== 3. Error bodies carry a correlation ID and leak no internals (ADR-014) ===
Every 403 and 401 response above was additionally asserted (inline, not
shown per-row) to: deserialize as ApiErrorResponse with ErrorCode
"FORBIDDEN"/"UNAUTHORIZED"; carry a non-empty CorrelationId; and contain
none of {"Exception", "   at ", ".vb:line", "SELECT ", "INSERT ", "UPDATE ",
"DELETE ", "Server=", "Uid=", "Pwd=", "Password="} anywhere in the raw body.
All 16 checked responses (12 negative + 4 anonymous) passed - had any
failed, its assertion message would have named the leaked fragment and the
full body, and the test run above would show a failure instead of a pass.
