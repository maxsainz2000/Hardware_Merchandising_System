=== 3. Shape check ===
$ mysql -u root -e "SHOW TABLES FROM merchandising; DESCRIBE merchandising.products; DESCRIBE merchandising.categories; DESCRIBE merchandising.brands; DESCRIBE merchandising.units; DESCRIBE merchandising.productbarcodes; DESCRIBE merchandising.pricehistory; SHOW INDEX FROM merchandising.products;"

19 tables (14 baseline + brands, categories, pricehistory, productbarcodes,
units).

products: Id, Sku(UNI), Barcode(index), Name(index), Description(TEXT NULL),
CategoryId(FK, nullable), BrandId(FK, nullable), UnitId(FK, nullable),
Price DECIMAL(19,4), Cost DECIMAL(19,4), ReorderLevel DECIMAL(19,3) DEFAULT
0.000, IsActive, RowVersion BIGINT DEFAULT 0, CreatedAtUtc, UpdatedAtUtc,
ActiveBarcode (VIRTUAL GENERATED, UNIQUE).

categories / brands: Id, Name(UNI), CreatedAtUtc, UpdatedAtUtc.
units: Id, Name(UNI, 50 chars), CreatedAtUtc, UpdatedAtUtc.
productbarcodes: Id, ProductId(FK), Barcode(UNI), CreatedAtUtc.
pricehistory: Id, ProductId(FK), ChangedField, OldValue DECIMAL(19,4),
NewValue DECIMAL(19,4), ActorUserId(FK), EffectiveAtUtc, CorrelationId,
CreatedAtUtc.

products indexes: PRIMARY(Id), UQ_Products_Sku(Sku),
UQ_Products_ActiveBarcode(ActiveBarcode), FK_Products_Categories(CategoryId),
FK_Products_Brands(BrandId), FK_Products_Units(UnitId),
IX_Products_Barcode(Barcode), IX_Products_Name(Name).

  [PASS] all five spec section 12 product-master tables present
         (Categories, Brands, Units, ProductBarcodes, PriceHistory), plus
         the Products columns P1-07 deliberately left out.
  [PASS] indexes present for SKU, barcode, product name (this migration's
         own tables - "supplier name" belongs to Suppliers, db/migrations/
         0007_suppliers.sql, Track D / P2-10, not built here).

=== 4. Foreign keys prevent deletion of a referenced product (as root, to
       isolate the FK constraint from merch_api's own privilege-level
       denial on DELETE FROM products, which is a separate, pre-existing
       guarantee from 0002_post-migration-grants.sql) ===
$ mysql -u root -e "DELETE FROM merchandising.products WHERE Sku='P2-06-PRECISION';"
ERROR 1451 (23000): Cannot delete or update a parent row: a foreign key
constraint fails (`merchandising`.`pricehistory`, CONSTRAINT
`FK_PriceHistory_Products` FOREIGN KEY (`ProductId`) REFERENCES `products`
(`Id`))
  [PASS] a product referenced by PriceHistory cannot be deleted - proven by
  the error, not asserted by inspection.

=== 5. PriceHistory proven append-only by privilege (merch_api) ===
$ mysql -u merch_api merchandising -e "UPDATE pricehistory SET OldValue=0 WHERE Id=1;"
ERROR 1142 (42000): UPDATE command denied to user 'merch_api'@'localhost' for
table `merchandising`.`pricehistory`
$ mysql -u merch_api merchandising -e "DELETE FROM pricehistory WHERE Id=1;"
ERROR 1142 (42000): DELETE command denied to user 'merch_api'@'localhost' for
table `merchandising`.`pricehistory`
  [PASS] pricehistory is a ledger, granted INSERT only - same treatment as
  stockmovements/auditlogs.
