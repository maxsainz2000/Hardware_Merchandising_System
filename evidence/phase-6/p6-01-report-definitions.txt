4. A PRE-EXISTING, UNRELATED FAILURE FOUND AND FIXED ALONG THE WAY
---------------------------------------------------------------------

The first full pwsh ./scripts/run-tests.ps1 pass after this file first
existed came back 470/471 on the integration suite - one failure,
unrelated to anything this card touches:

  Failed GetLowStock_IncludesAtOrBelowReorderLevel_ExcludesAboveAndInactive
  Assert.IsTrue failed. 'condition' expression:
  'Await LowStockContainsSkuAsync(client, token, belowSku)'.
  A product at or below its own reorder level must be listed.

Confirmed pre-existing, not caused by this card: `git stash -u` back to
the unmodified tip (75b9d22, before any P6-01 file existed) reproduced
the identical failure running that one test alone.

Root cause, found by direct query against the real database
(merch_api): `Products` rows are permanent (no DELETE grant - ADR-013),
and this project has been run repeatedly since Phase 3/4. The number of
rows matching the real query's own WHERE clause -
`p.IsActive = 1 AND COALESCE(b.Quantity, 0.000) <= p.ReorderLevel` -
had grown to 2074 (most of them ReorderLevel-0.000 fixtures from other
files with no balance row at all, which the COALESCE always makes
low-stock). The test's own polling helper, LowStockContainsSkuAsync,
capped its scan at a hard-coded 20 pages x 100 rows = 2000 and gave up
after that - a limit that was never wrong when it was written, and had
just been exceeded by ordinary accumulation. The newly-created fixture
product in this run had Quantity 5.000, sorting (ORDER BY Quantity ASC)
after the 2036 rows below it - past row 2000, past the helper's own cap,
never reached.

Fix: src/tests/Merchandising.Tests.Integration/LowStockAndStockReviewTests.vb,
LowStockContainsSkuAsync - the fixed page cap is replaced with a loop
bounded by the response's own TotalCount, so the helper is correct for
any database size rather than "correct until the count doubles again."
Confirmed by re-running the isolated test (now passing) and the whole
file (8/8 passing) after the fix, before the final full-suite run below.
