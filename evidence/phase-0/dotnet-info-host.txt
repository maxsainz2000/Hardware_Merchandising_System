WHY THIS FILE LOOKS IDENTICAL TO dotnet-info-dev.txt
----------------------------------------------------
It is the same physical machine. Manifest section 1 (development machine)
and section 2 (reference host) both describe LAPTOP-3HH6OHHE: in the lab,
the build machine also serves as the API and database host.

This file was listed under manifest section 2 "Attach:" from the start but
did not exist on disk until 2026-08-18, when a pre-P1-06 health check
checked every referenced evidence path and found this one dangling. It is
captured here rather than deleted from the manifest, so the host row has
the artefact it claims.

PER ADR-012 THIS IS A LAB FACT, NOT A DELIVERABLE VALUE. The demo host is
a classmate machine that has not been surveyed (manifest section 3.2), and
crucially it will have NO .NET SDK -- so the ASP.NET Core runtime present
below exists here only because the SDK is installed. ADR-010 relies on
exactly that distinction: do not read this file as evidence that a demo
host can run framework-dependent output.
